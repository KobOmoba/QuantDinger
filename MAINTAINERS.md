# Maintainers and Sensitive Access

This file is the public record of project members who hold access to sensitive
QuantDinger resources. It is reviewed whenever access changes and at least once
per release cycle.

| Person | Role | Public identity | Sensitive access |
| --- | --- | --- | --- |
| QuantDinger Project Lead | Project Lead and maintainer | [@brokermr810](https://github.com/brokermr810) | GitHub repository administration, release approval, package publication, security reports |

Repository access is granted manually using the lowest role that can perform
the required task. New maintainers are reviewed by the Project Lead before
receiving write, release, security-advisory, or organization-level access.

Report an incorrect or outdated entry through a regular issue. Do not disclose
credentials or private security information in that issue.
